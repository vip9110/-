栗栗 · 小刺猬桌宠 3.0 重做版

启动与升级
适用：Windows 10 / Windows 11 64 位（x64）。
直接双击「栗栗桌宠.exe」。单文件便携程序，无需安装 Python、.NET 或其他运行库，不需要管理员权限。
如果旧版（2.x）正在运行，3.0 会询问是否自动关闭旧版：旧版会先保存进度，3.0 直接沿用，不需要重新开始。
程序未做数字签名，Windows 可能提示“发布者未知”。

和栗栗相处
单击：摸摸它，心情 +2，会开心地蹦一下。
鼠标在栗栗身上来回轻抚（不用点击）：也算摸摸，它会眯眼享受。
鼠标靠近：它会转头看向鼠标。
左键拖动：换位置；靠近显示器左右边缘松手会自动停靠并滑到边上。
双击或右键：打开「栗栗的生活馆」。
中键：快捷菜单。
Ctrl + 滚轮（鼠标在栗栗身上）：调整大小。
拖着文件停在栗栗身上：它会凑过来嗅嗅；松手后文件只进入待确认清单。
托盘：单击找回，双击打开生活馆，右键打开菜单。
生活馆右上角 X 只收起面板；完整退出请用设置页或托盘菜单中的「退出桌宠」。

快捷键（设置页可切换）
默认「快速按两下 Esc」隐藏 / 显示。Esc 仍会正常传给其他软件，不会被占用。
也可以选「Esc（独占）」（2.1 的旧方式，会占用所有软件的 Esc）、Ctrl+Alt+H，或关闭快捷键。
从 2.1 升级时，旧的独占 Esc 会自动改为双击 Esc，需要旧方式可在设置页改回。
选择文件和确认回收时暂时释放快捷键。

生活馆的六个页面
小窝：饱食度、健康、心情、精力、体重、每日金币、累计喂食 / 相伴天数 / 摸摸次数，以及「看看小动作」（8 种）。
文件喂食：拖入或选择文件、待确认清单（点选 / Ctrl 多选 / Shift 连选 / 全选 / 每行 × 移除 / Delete 键 / 双击在资源管理器中定位）、确认回收、打开回收站、回收站感应开关。
小商店：养护药、营养片、逗逗球、小围巾、软软睡窝、运动铃。
照护：用药、营养片、免费陪伴、休息、踏步（可提前结束）、玩球、穿戴围巾。
设置：快捷键、停靠、大小（60% / 75% / 100% / 135% / 160%）、不透明度、动画帧率、自动散步、置顶、回收站感应、鼠标穿透、全屏时隐藏、开机自启、启动时打开生活馆、自动作息、闲聊气泡、回到右下角、隐藏、退出。
使用说明：右上角按钮打开。
键盘：Tab / 方向键切换按钮，Enter / 空格确认，Ctrl + Tab 切换页面，Esc 收起生活馆。

文件喂食
方式一：把不再需要的本地文件或文件夹拖到栗栗身上或生活馆窗口，或点「选择文件」「选择文件夹」。
项目只进入待确认清单。点击「确认移入回收站并喂食」，检查清单并选择「是」，才执行回收。
文件夹包含内部内容，目录整体按一项计入奖励；重复或被父文件夹覆盖的条目会去重。
成功回收后，原位置不再显示这些项目，可以在 Windows 回收站中恢复。
只在确认成功进入回收站后增加饱食度和金币；失败或取消不会发奖励。
可能出现 Windows 自带的回收确认或进度窗口；若系统提示无法回收或要永久删除，请取消。

方式二：回收站感应（默认开启）。
你平常在 Windows 中把文件删除到回收站后，栗栗感应到数量增加并触发吃文件动画。
此方式只读取数量，不会打开、再次移动或清空回收站里的文件。在后台线程约每十秒检测一次，不会让界面卡顿。
启动前已有的项目不补算；同一检测期间删除和恢复相互抵消时可能不计入。

回收保护
只接受本机固定磁盘的普通路径，拒绝整盘、系统 / 程序 / 设置目录、整个用户常用文件夹、桌宠本体及其父文件夹。
拒绝网络盘、U 盘、符号链接 / 联接、云占位路径、通配符和超长路径。
可以从桌面、文档、下载等目录中选择普通的、不再需要的子项目。
操作前重新检查路径；发现回收条件不满足时中止，不调用永久删除接口作为替代。
不提供清空回收站或永久删除功能。回收能力仍受 Windows 磁盘与回收站配置影响。
请先用专门创建的临时文件和临时文件夹试用，并验证能从系统回收站还原。

养成规则（与 2.1 相同）
饱食度随运行时间缓慢下降，成功回收后增加，每批最多 +25。
长期饥饿、过饱、低精力及体重异常会降低健康；休息、药品、免费照护帮助恢复。
健康低于 45 时生病，使用生病姿态并暂停散步；恢复到 70 后康复。
喂食增加体重，运动减少体重；380–580 g 为匀称区间，体型宽度随体重变化。
活动消耗精力，睡眠恢复精力。生病或精力过低时不开始运动；踏步中生病或精力低于 10 会自动结束。
自动作息（默认开启）：精力低于 12 会自己打盹，恢复到 85 后自己醒来；随时可以手动叫醒。
摸摸、玩球、照护、喂食改善心情。
关闭程序后不补扣离线时间；隐藏后仍缓慢更新状态和感应回收站。
没有死亡、强制付费或因生病删除文件的机制。

金币与商店
金币是本地游戏数值，无真实支付。初始 80 金币并附送一份养护药，每日礼物 +20。
每个新回收条目 +3 金币，每批最多 +40。请只处理确实不再需要的文件。
养护药 25：健康 +35、精力 +8，在照护页使用。
营养片 18：健康 +12、精力 +20，在照护页使用。
逗逗球 60：永久解锁玩耍动作，改善心情。
小围巾 90：永久解锁，可穿戴和收起；3.0 起所有动作都戴得住。
软软睡窝 80：永久解锁，提高睡觉恢复速度，睡觉时显示小窝。
运动铃 60：永久解锁，提高运动时的体重消耗，踏步时会摇晃。
免费陪伴：健康 +8、心情 +10，五分钟冷却。

更省电
动画按显示比例预先烘焙，身体用自带合成器绘制；安静站立、睡觉时自动降低刷新频率。
设置页可选「省电 · 30 帧」。开启「全屏时隐藏」后，看视频、玩游戏时栗栗会自动躲起来并暂停绘制。

本地数据
设置与进度：%LOCALAPPDATA%\LiliDesktopPet\settings.ini（沿用 2.1 的文件与键名）。
每三十秒、操作后稍等片刻和退出时保存；先写临时文件再替换，避免断电损坏。待回收清单不写入磁盘。
需要重置时先退出程序，再删除该设置文件。
程序离线运行，不联网。开机自启默认关闭，在设置页开启后只写入当前用户的启动项，关闭即删除。

找不到栗栗时
单击托盘图标找回；或在托盘菜单选「回到屏幕右下角」（同时会关闭鼠标穿透）。
若开启了「全屏时隐藏」，退出全屏后它会自己回来。
